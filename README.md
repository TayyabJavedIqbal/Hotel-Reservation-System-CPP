# Hotel Reservation System (C++)

A comprehensive console-based application designed to manage hotel operations, including room booking, customer record management, and a food ordering system.

## 🚀 Key Features
- **Room Booking:** Categorized rooms (Single, Double, AC) with automatic price calculation.
- **Data Persistence:** Uses C++ File Handling (Binary mode) to save/load records in `Record.txt`.
- **User Roles:** Separate interfaces for **Owners** (to manage records) and **Customers** (to order food).
- **CRUD Operations:** Ability to Create, Read, Update, and Delete customer details.

## 🛠 Tech Stack
- **Language:** C++
- **Concepts:** Object-Oriented Programming (Classes/Inheritance), File I/O, Error Handling.

## 📝 How to Run
1. Clone the repository.
2. Compile using any C++ compiler (G++, CodeBlocks, or Visual Studio).
3. Run the executable.
